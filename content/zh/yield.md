## 核心设计：恒定 $1.00 + 新增代币空投

USDBOND 的收益分配采用**恒定 NAV + 新增 USDB 空投**模式。每枚 USDB 始终锚定 $1.00，国债利息不改变代币价格，而是通过每日铸造新 USDB 代币并空投至合格持有人钱包来实现收益分配。

这意味着 USDB **不采用**以下任何一种常见模式：

| 模式 | USDBOND 是否采用 | 说明 |
| - | :-: | - |
| **Rebasing（弹性供应）** | 否 | 不改变持有人钱包中的代币余额数量与单价的关系 |
| **NAV 增值（份额价格上涨）** | 否 | 份额价格恒定 $1.00，不随收益累积上涨 |
| **质押 / 锁仓生息** | 否 | 无需质押、锁定或主动领取 |
| **手动领取（claim）** | 否 | 收益自动到达钱包 |
| **新增代币空投** | **是** | 每日铸造新 USDB 并空投至合格持有人地址 |

### 与 Franklin Templeton BENJI 的一致性

USDBOND 的机制设计与 BENJI 完全一致：

- BENJI 通过**每日铸造新 BENJI 代币并直接空投至股东钱包**的方式分配收益，而非通过 NAV 变化。
- BENJI 的**每日链上股息分配全年 365 天运行，包括周末和假日**。
- BENJI 的收益**按秒级**在代币转账时累积。
- BENJI 是当前唯一实现全年 365 天每日链上股息分配能力的代币化货币市场基金。

WisdomTree 的 WTGXX 也推出了**连续股息应计**功能，使份额能够根据每个已验证钱包持有代币的时间长度来分配每日收入，利用区块链时间戳追踪日内转账。

## 365 天连续运行的三个前提

传统货币市场基金的分红通常在**工作日**进行。USDBOND 的设计目标是**全年 365 天每日分配**，包括周末和假日。这要求以下三个机制同时成立：

| 机制 | 要求 |
| - | - |
| **链下收益的每日应计** | 国债利息按日应计，即使在非交易日，利息仍在累积（国债利息按实际天数计算，含周末和假日） |
| **链上铸造的每日执行** | 智能合约每日执行一次铸造和空投操作，不受传统金融市场交易日历限制 |
| **利率数据的每日同步** | 通过预言机或链下计算引擎，每日将应计收益率同步至链上 |

## 空投计算公式

每日空投的 USDB 数量按下式计算：

**每日空投 USDBᵢ = 持有 USDBᵢ × (当日基金净收入 ÷ 基金总流通份额) × (1 − 管理费率)**

公式中各项的含义：

| 变量 | 定义 |
| - | - |
| **持有 USDBᵢ** | 合格地址 i 在快照时的 USDB 余额 |
| **当日基金净收入** | 基金当日国债利息收入减去运营费用后的净额 |
| **基金总流通份额** | 快照时基金流通中的 USDB 总数量 |
| **管理费率** | 年化管理费（如 0.15%），按日折算扣除 |

### 收益测算示例

以当前短期美国国债收益率约 **3.5%**、管理费率 **0.15%** 年化计算：

| 本金 | 年化净收益率 | 年收益 | 相比 USDT/USDC |
| - | :-: | :-: | :-: |
| $10,000 | ~3.35% | ~$335 | +$335 |
| $100,000 | ~3.35% | ~$3,350 | +$3,350 |
| $1,000,000 | ~3.35% | ~$33,500 | +$33,500 |
| $10,000,000 | ~3.35% | ~$335,000 | +$335,000 |

持有 USDT 或 USDC 的同期收益为 **0%**。上表为按固定收益率测算的示意，实际收益随国债收益率与基金净收入每日变动，不构成收益承诺。

## 合格持有人的定义

**空投的合格用户是空投时合格的 USDB 持有地址。** 资格以快照时点的状态为准，而非以申购时点或持有历史长度为准。

### 快照时点

每日 **UTC 00:00**（或协议治理确定的其他固定时点）对链上 USDB 持有地址进行快照。

### 合格条件

地址须同时满足以下全部条件：

1. 已在转让代理处完成 **KYC/AML 验证**并被纳入**白名单**。
2. 在快照时点持有 USDB 代币余额（余额 > 0）。
3. 不处于**锁定期、冻结状态或制裁名单**中。
4. 不位于受限制司法管辖区。

### 不合格地址的处理

未通过 KYC 的钱包地址、受制裁地址、以及协议治理明确排除的地址不具备空投资格。**不合格地址持有的 USDB 仍可赎回本金（$1.00/枚），但不获得收益空投。**

> **为什么这样设计**：USDB 是 1940 年《投资公司法》下的注册投资公司份额，属于证券。收益分配只能面向已完成 KYC/AML 验证的合格持有人，这是证券法合规架构的组成部分，而不是可选的运营策略。

## 空投的执行流程

每日空投由链下收益计算与链上执行协同完成，共五个步骤：

| 步骤 | 环境 | 内容 |
| - | - | - |
| **一、收益计算** | 链下 | 基金行政管理人计算当日国债利息应计额，扣除管理费后得到可分配净收入 |
| **二、快照** | 链上 | 在预定快照时点，智能合约记录所有合格地址的 USDB 余额 |
| **三、铸造** | 链上 | 根据收益计算和快照结果，智能合约调用 `mint` 函数铸造相应数量的新 USDB 至待分配地址池 |
| **四、空投** | 链上 | 智能合约按各地址持有比例，通过批量转账或 Merkle 分发将新 USDB 分配至合格持有人钱包 |
| **五、记录更新** | 链上 | 转让代理更新官方股东名册，反映新增份额 |

空投通过**批量转账**或 **Merkle 分发**方式执行，以优化 gas 成本。

## 空投执行风险

每日空投依赖链下收益计算与链上执行的协调。**预言机延迟、数据偏差或快照时点的技术故障可能导致空投数量不准确或分配失败。** 空投合约须经过第三方安全审计。完整的风险清单见[风险因素](/zh/risks/)页面。

## 常见问题

### Q: 持有 USDB 的收益是多少？

按 3.5% 的短期美国国债收益率、扣除 0.15% 年化管理费测算，净年化收益约为 3.35%。实际收益随国债收益率与基金每日净收入变动，不构成收益承诺。

### Q: USDB 的收益需要质押或锁定才能获得吗？

不需要。持有人无需质押、锁定或主动领取，收益以每日空投的新增 USDB 代币形式自动到达钱包。USDB 不采用质押生息或手动 claim 模式。

### Q: USDB 每天什么时候空投？

每日 **UTC 00:00** 对链上 USDB 持有地址进行快照，随后执行收益计算、铸造与空投。分配全年 365 天运行，包括周末和假日。

### Q: 周末和假日也会分配收益吗？

会。USDBOND 的设计目标是全年 365 天每日分配。国债利息按实际天数计算，含周末和假日，因此即使在非交易日利息仍在累积，链上铸造也不受传统金融市场交易日历限制。

### Q: Rebasing 和空投有什么区别？

Rebasing 会改变代币的价格或持有人余额与价格的关系；USDBOND 保持每枚 USDB 恒定锚定 $1.00，收益以**新增**代币的形式空投给合格持有人，原有代币的数量与单价都不变。

### Q: 如果我不通过 KYC，还能持有 USDB 吗？

不合格地址持有的 USDB 仍可赎回本金（$1.00/枚），但不获得收益空投。空投资格要求地址在快照时已完成 KYC/AML 验证、被纳入白名单、不处于锁定期/冻结/制裁状态，且不位于受限制司法管辖区。

### Q: 空投的收益是如何计算的？

每日空投 USDBᵢ = 持有 USDBᵢ × (当日基金净收入 ÷ 基金总流通份额) × (1 − 管理费率)。即按合格地址在快照时的持仓占基金总流通份额的比例，分配扣除管理费后的当日净收入。
